# My Secret Weapon — Animated Chat Website

A single-file responsive website generated from the uploaded conversation archive.

## Included
- 44 conversation messages
- Chronological order
- Animated chat bubbles
- Play / Pause / Replay controls
- Animated star background
- Tenor sticker previews
- TikTok links rendered as clickable links
- Mobile-friendly glassmorphism UI

## Run
Open `index.html` in a browser.

## Deploy
Upload `index.html` to GitHub Pages, Netlify, Vercel, or any static hosting service.
